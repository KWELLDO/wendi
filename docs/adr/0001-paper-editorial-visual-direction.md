# 0001 · 视觉方向:大报编辑体(wendi 化)

- 状态:accepted
- 日期:2026-09-27

主界面/图谱/计量台此前是三套互不相关的暗色观感(暗灰 + 金为主),无排版层级、无主张;实测线上四屏后,决定采用设计库 `editorial-broadsheet`(大报编辑体)的**材质与排版契约**重做用户可见面:新闻纸底 + 近黑墨 + 单一编辑红 + 发丝线 + 方角,衬线/无衬线/等宽三层字体;亮色默认、夜版跟随系统(`prefers-color-scheme`,无切换按钮);**只取契约层,不搬刊物词法**(无报头/三栏/大写标签等报纸道具);交互性动效保留(房间进出/流式/气泡),装饰动效清零。本次范围 `web/index.html` + `web/graph2d.html`。

## Considered Options

- **家族「档案纸 · 编辑体」**(象牙 + 藏青 + 金):与 kwelldo 站群同源,但气质更"档案室";且"红 = 入口"的语义更贴"划词"这个核心交互。
- **保留暗色并精修**:方向不变,失败模式不变(无主张)。
- **`dark-academia`(暗色书斋)**:戏剧化、长期易腻,且与"不评判"的产品立场相冲。

## Consequences

- 分享卡片(canvas)按同套 token 重绘为"纸片剪报";分享卡不随夜版反色——纸制品是印刷物。
- 夜版为新增设计物(此前不存在);设计库 `editorial-broadsheet` spec 的暗色块由本项目首定义。
- `meter.html`(站长后台)与 3D 实验室暂不换皮;窄屏只保"不塌";触屏划词是行为缺陷,另行立项。
