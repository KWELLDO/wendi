# 第一部分 · 这个项目是什么

## 1. 一句话

**问底是一个"递归解释器"：在阅读中划选任何不懂的词，就地得到结合语境的解释；解释里还有不懂的，继续划，一层层问到底。**

在线体验：https://know.kwelldo.cn · 源码：AGPL-3.0（见 LICENSE）

## 2. 它解决什么问题

用 AI 学习新领域时，最大的障碍不是信息不够，而是**术语过载**——AI 默认你拿着它的术语表说话。传统补救是"追问"，但追问是线性的：

1. 你问"什么是叠加态"，AI 解释了；
2. 解释里又出现"波函数坍缩"；
3. 你追问"什么是坍缩"，回来时**原来那段话已经滚走了**；
4. 两三轮之后，你迷失在聊天记录里，语境断裂，只能重开对话。

问底把这件事从"对话流"改造成"**可回退的空间**"：每次划词生成一张**就地展开的解释卡**，原句不动；解释卡里的新术语还能继续划，形成一棵**你自己的困惑之树**。学习过程第一次有了空间结构——能进入、能返回、能总览。

## 3. 核心交互（四步）

| 步骤 | 操作 | 发生什么 |
|---|---|---|
| ① 提问 | 在主对话输入问题 | AI 回答成为"可划词的材料" |
| ② 划词 | 鼠标划选任何词/短语 | 就地弹出金色的「解释」气泡 |
| ③ 下钻 | 点击解释 → 生成解释卡 | 结合**该词所处的句子**解释，不是词典义 |
| ④ 递归/回退 | 卡内继续划词；`Esc` 或 `Alt+←` 返回上一层；`↑↓` 切换兄弟解释；`Alt+Enter` / `Alt+→` 进入 | 深度无限，路径可逆，一切可回退 |

辅助能力：三档解释深度（说人话 / 标准 / 严谨）、划词时附一句自己的疑惑（解释先答它）、卡内追问、解释重讲、LaTeX 公式排版（KaTeX 内置）、导出整棵树为 Markdown、30 秒引导教程、设置面板（反馈 / 账号与同步 / 数据 / 关于；站长项默认隐藏）、右下角常驻反馈入口。

**"分形房间"隐喻**：每一层都是一个同构的房间——左边正文，右上是本层解释列表，右下是下一层的缩小预览。进入/返回是摄像机移动，深浅不会把字挤小。这解决了递归界面最常见的"套娃越缩越小"问题。

## 4. 设计立场（这个产品的宪法）

这四条不是功能列表，是**拒绝做某些功能**的承诺，全部推导自理论文档 `docs/clarity-and-vagueness.md`（含糊与清晰的辩证关系）：

1. **不评判** —— 没有"这么简单都不懂"，没有熟练度红绿，没有"已掌握/待复习"。困惑是学习材料，不是待消灭的缺陷。
2. **解释是材料，不是答案** —— 系统不给"这就是全部"的终审结论，判断永远在读者手里。
3. **允许含糊** —— 一词多解就并列呈现，不强行收敛；近义词不自动合并；图谱不为概念强制命名聚类。
4. **数据主权** —— 记录默认留在用户自己的浏览器（`localStorage`）；服务端只转发请求、托管账户；云同步是用户主动的备份行为。

这四条也是这个项目的辨识度所在：交互可以被抄袭，但一套一贯的立场凝聚出的用户信任与品牌声音，抄不走。

## 5. 功能全景

**已实现（v0.2.x）**
- 划词递归解释 + 分形房间导航 + 键盘全操作
- 三档解释深度；卡内追问；重讲
- 主对话（问题意识入口）+ 示例问题 + 30 秒引导教程
- 导出 Markdown
- 账户系统（开放注册；匿名 20/天、免费 40/天、增值 Pro 300/天）、增值兑换码
- 云同步（本地优先，主动备份/载入）
- SSE 流式输出（划词/追问/对话边生成边显示）
- 内核事件缝（`explain.done / explain.error`），为扩展子系统预留

**已实现（随 v0.2.x）**
- 2D 图谱 `web/graph2d.html`：轮次时间线 + 来源栏，当前视图 → PNG（纸色落款带、不随夜版反色）+ 图谱结构 JSON（解释卡正文/语境/追问，不含对话原文）
- 分享卡片：解释树切片的只读渲染，PNG + JSON
- 反馈管线：站内反馈 → 站内消息 → Agent 辅助分诊

**规划（见 memo.md 路线图）**
- 知识图谱正式版（术语卡积累成网）
- 多会话/多主题
- 笔记（卡片批注）
- 分享 permalink（只读链接）
- 团队版

## 6. 技术架构

```
web/app/index.html 工作台（单文件、零构建）：分形房间 + 摄像机 + 键盘导航 + SSE 渲染；web/index.html 为落地页
web/vendor/katex 内置 KaTeX：正文/解释/预览里的 LaTeX 排版
server.py        薄代理：LLM 转发（多 key 轮换）+ 限流 + 配额 + 账户 + 兑换码 + 云同步
kernel.py        内核：事件总线 + 服务注册 + 作用域生命周期（借鉴 cordis 语义，纯标准库）
prompts.py       提示词资产——这个项目真正的核心软件资产：解释器人格三件套
db.py / auth.py  SQLite 数据层 + PBKDF2 认证
deploy/          systemd + nginx 幂等部署件
tests/           内核测试
```

三个刻意坚持的工程约束：

1. **零第三方依赖（后端只用 Python 标准库）**——部署成本趋近于零，一台任意 VPS 即可运行；安全面极小。
2. **前端单文件零构建**——没有 node_modules，没有构建链；产品迭代周期以小时计。
3. **提示词即核心资产**——`prompts.py` 里沉淀的是"解释器人格"（不评判、语境化、允许并列），模型可换（任何 OpenAI 兼容端点），人格可迁移。

代码规模约 2500 行（后端 ~800，前端 ~900，测试与部署件其余）。单人可维护。

**模型无关**：默认 DeepSeek（便宜），任何 OpenAI 兼容端点可替换；自部署者填自己的 key，成本完全自持。

## 7. 部署形态

- 官方实例：`know.kwelldo.cn`（腾讯云单机 + systemd + nginx 反代 + 免费证书）
- 交付形态：**AGPL-3.0 开源 + 官方托管实例**。欢迎自部署（后端零第三方依赖，自填 `WENDI_API_KEY` 即自备模型 key）
- 数据：SQLite 单文件 + 用户浏览器 localStorage；无大数据基础设施
