隐私政策

这份文档只描述这个项目实际做了什么，不写做不到的承诺。默认状态是：你的学习记录不出你的浏览器。

最后更新 2026-09-27。测试期文档，随功能变化更新。

收集什么 · 不收集什么

会处理的

  • 你在工作台划出的词，以及它所在的句子；卡内追问与主对话时是最近的对话内容。用于当次解释。
  • 账号信息：邮箱与密码（密码只以加盐哈希形式保存）。匿名使用不需要注册。
  • 可选上传的云同步数据：你的学习记录文本。
  • 用量计量：时间、账号（或匿名时的 IP）、模式、风格、是否流式、token 数、折算成本、解释树深度与对话轮数。
  • 内测期的行为事件：你在工作台里做了哪个动作（打开、划词、请求解释、进入下一层、回退、导出、生成分享卡、提交反馈、注册、登录、以及服务端出错），以及时间、会话标识、层级深度、你带来的邀请码。用于回答「谁来了、卡在哪、有没有人第二次回来」。
  • 服务器访问日志：IP 与请求记录，用于运维和防滥用。

不会做的

  • 服务端不存储你的提问与解释正文。请求转发出去、结果返回之后，正文不在服务端留下。
  • 不把本地记录自动上传。没有你的点击，同步不会发生。
  • 用量计量与行为事件里都不含正文内容：你划的词、提问、解释卡的文字都不会进这两张表。
  • 不留原始 IP：行为事件里只存加盐哈希（不可反推），原始地址只在服务器访问日志里为运维与防滥用保留。
  • 没有广告位，没有把数据交给数据经纪方的业务。
  • 匿名使用不需要邮箱，也就没有对应的账号档案。

数据存在哪里

数据存在哪里怎么才会过去
学习记录（提问、解释卡、层级树）你自己浏览器的 localStorage默认就在本地，不上传
云端副本服务器，按账号只保存这一份文本登录后你主动点「同步↑」才上传，覆盖式，单账号 ≤1MB
账号服务器（邮箱 + 密码哈希）你注册时才产生
用量计量服务器每次发起 AI 请求时自动记录，不含正文
访问日志服务器nginx / systemd 自动记录

服务器位于中国大陆（腾讯云）。自部署版本的数据存在你自己的机器上，与这个站点无关。

什么时候会发给第三方

只有一种情况：你发起一次 AI 请求时，服务端会把「你划的词 + 所在句子」（卡内追问与主对话时是最近的对话内容）转发给大模型服务，默认是 DeepSeek，走 OpenAI 兼容接口。

转发的范围就是为了完成这一次解释所必需的那一小段文本。服务端自身不存储这些正文。第三方如何处理请求，取决于该大模型服务自己的条款，这一点本项目无法替它承诺。

除此之外，不向任何第三方提供你的数据。自部署时，请求由你自己带到你自己配置的服务商。

用量计量记了什么

计量是为了知道这个服务在真实使用下的成本，逐项如下：

字段内容
时间请求发生的时间
账号已登录时是账号；匿名时是 IP
模式划词解释 / 卡内追问 / 主对话
风格该次请求使用的解释风格
是否流式流式输出或一次性返回
token 数输入 token 数与输出 token 数
成本按单价折算的人民币金额
结构指标解释树深度、对话轮数

不含正文内容。计量表里没有你划过的词，也没有解释卡的文字。

行为事件（内测期）

为了判断这个交互到底有没有人需要，服务端会记录上面那组动作事件。它记的是**动作本身**，不是内容。

记什么不记什么
事件名、时间、会话标识、账号或 IP 哈希、邀请码、层级深度、少量元数据（如生成耗时、是否截断）你划的词、所在句子、提问、解释卡正文、按键序列、鼠标轨迹

身份归属按「邀请码 > 账号 > IP 哈希」的优先级确定一条事件属于谁；没有账号、也没有邀请码的匿名访问，只会留下一个不可逆的 IP 哈希。

事件流水保留 90 天，之后自动删除；按天汇总的统计数字（活跃人数、解释次数、成本等）不设期限，用于长期判断产品走向，但不含个人明细。这两种记录都不会被卖给或分享给第三方。

日志与 IP

服务器使用 nginx 与 systemd，它们的访问日志会记录 IP。目的是运维排障与防滥用——例如配额按 IP 计数、识别异常请求。匿名使用时，IP 也会出现在用量计量里，因为那是区分匿名额度归属的唯一依据。

保留期

本地记录
你说了算。清空浏览器数据或在工作台里清空记录，它就没了，服务端没有任何备份。
云端副本
删了即删。执行「删除云端副本」后不可恢复，服务端不留副本、不留历史版本。
账号
保留到你申请删除为止。删除账号目前走反馈页人工处理。
行为事件
保留 90 天，之后自动删除；按天的汇总数字长期保留（不含个人明细）。
用量计量与反馈
保留用于成本核算与产品改进。计量记录不含正文；反馈内容由你自愿填写。
访问日志
由服务器日志轮转策略决定，用于运维与防滥用。

你的权利

  • 导出：把学习记录导出为 Markdown 或 JSON。
  • 清空本地：随时清掉浏览器里的记录，不需要经过任何人。
  • 删除云端副本：登录后随时可以删掉服务器上那份同步文本，删除即不可恢复。
  • 申请删除账号：通过反馈页提出，由站长人工处理。这个项目没有自动化注销流程，也不承诺处理时限。

Cookie 与 localStorage

  • 登录会话 token：登录后存在浏览器里，有效期 90 天，用于保持登录状态。
  • 本地学习记录：提问、解释卡、层级树，默认只在这里。
  • 界面偏好：界面上的一些设置项，同样存在浏览器本地。

这些都在你自己的浏览器里。清空浏览器数据会一并清掉，包括登录状态。

未成年人

服务处在小范围内测阶段，没有面向未成年人设计，也没有年龄核验机制。未成年人请在监护人知情同意后使用；如果监护人不同意，请不要使用。监护人有疑问可以通过反馈页联系。

安全措施与局限

做了的

  • 密码使用 PBKDF2-HMAC-SHA256，20 万轮加盐；服务端不存明文密码。
  • 站点通过 HTTPS 访问。
  • 服务端按最小权限处理数据：不需要的正文不留，不需要的字段不记。

没能承诺的

  • 不承诺绝对安全。任何系统都不该被这样承诺，这个由一个人业余维护的测试期项目尤其不该。
  • 没有可以援引的第三方安全审计或认证，请不要把它当作经过审计的系统来使用。
  • 密钥配置、软件依赖、运维环节都可能有疏漏；发现问题请走反馈页，会尽力修。

变更与联系

这份政策会随功能调整而更新，更新时会改写页面顶部的「最后更新」日期。涉及数据处理方式的实质变化会在这里写清楚，而不是只在版本号上体现。

问题、异议、删除账号申请：反馈页，或源码仓库 Issue（GitHub KWELLDO/wendi）。能回就回，不承诺响应时间。
