这些键是什么

        
    
          
  • cost_cents_cap：当日累计成本过线 → 全员降级（输出变短、同一人多 15 秒限速，用户侧显示「降速」）。
    • 
          
  • cost_cents_hard：再过线 → 当日硬停（429），次日恢复。必须大于 cap。
    • 
          
  • degrade_min_interval / degrade_max_tokens / degrade_max_tokens_chat：降级档的间隔与输出上限。
    • 
          
  • flash_*：DeepSeek 单价（美元 / 百万 token，峰谷分开），用于把 token 折算成人民币成本；usd_to_cny 是汇率。
