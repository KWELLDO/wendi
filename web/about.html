关于 wendi

问底 WenDi 是一个递归解释器。遇到不懂的词，就划它；解释里还有不懂的，继续划，一层层到底。

这是什么

问底只做一件事：把你此刻不懂的那个词，按它出现在当前句子里的意思解释开——结合该词所在句子的语境，给出的是语境义，不是词典条目。而这张解释卡本身不是终点：卡里还有不懂的词，照样可以继续划下去。

每一层都是同构的房间。进入和返回是摄像机在层级之间移动，所以无论走多深，字都不会被挤小。按 Esc 回退一层。整棵层级树可以导出成 Markdown 或 JSON，留在你手里。

怎么用

  1. 划词：在工作台上划出你不懂的那个词，它会连同所在句子一起被理解。
  2. 进入解释：得到一张解释卡，平级陈列这个词在语境里的理解。
  3. 继续划，或者回退：卡里还有不懂的词就继续划，一层层往下；按 Esc 一层层往回。

和词典、聊天机器人的区别

它是什么给出来的东西接下来能做什么
词典词条的标准义，脱离你读到的那句话自己把释义搬回句子里对照
聊天机器人一段完整的回答接着追问，答案越滚越长
问底 WenDi这个词在当前这句话里的意思继续划解释里的词，直到你不再需要划

差别不在答案长短，而在谁负责判断。问底不替读者下结论，解释是材料，检验与判断留在读者手里。

它不做什么

下面四条是这个项目的立场，属于产品宪法，不随版本改动。

不评判
没有「这么简单都不懂」。不懂是常态，不是缺陷。
解释是材料，不是答案
判断与检验在读者手里。这个项目负责把材料摊开，不负责替你收尾。
允许含糊
一种词有多种理解，就并列给出，不强行收敛成唯一一种。
数据主权
记录留在你自己的浏览器里。上传与否，是一个由你手动发起的动作。

三条明确不做

  • 不做评判。
  • 不替用户下结论。
  • 不把用户的困惑变成焦虑。

你的数据在哪里

默认只在本地
学习记录（提问、解释卡、层级树）默认只存在你自己浏览器的 localStorage 里，不上传。
云同步是可选动作
登录之后主动点「同步↑」，才会把数据上传到服务器：单账号上限 1MB，覆盖式写入，服务端按账号只保存这一份文本。
AI 请求正文不另存
发起一次 AI 请求时，服务端会把「你划的词 + 所在句子（或最近对话）」转发给大模型服务；服务端自身不存储你的提问与解释正文。
反馈分诊不拿联系方式
提交反馈后，反馈正文、必要元数据与账号 ID 可能交给大模型辅助分诊、生成处理方案；你填写的联系方式字段不会发送，正文中识别出的邮箱、手机号和带标签的联系方式会先脱敏。开发 Agent 对大改只写方案；小修只在隔离副本里生成候选补丁，不自动合并或部署。
站内消息
Agent 或站长需要向你确认信息时，会按账号留下站内消息；你可以在消息页查看。不承诺处理时间或修复结果。
云端副本随时可删
可以随时「删除云端副本」，删了即不可恢复。

逐项细节——包括用量计量记录了哪些字段、日志保留多久、如何申请删除账号——都写在隐私政策里。

现在是什么状态

小范围内测未对外推广功能与数值都可能变

  • 服务处于小范围内测阶段，只在小范围试用，尚未对外推广。
  • 到目前为止用的人很少：它是刚能被用起来的样子，不是成品。
  • 功能可能变：界面、交互、导出格式都在调整中。
  • 数值可能调：配额与相关参数属于测试期数值，会按实际运行情况调整。

想找什么样的第一个用户

正在被术语困扰的人：读论文的研究者、学新技术的程序员、跨领域自学者。判断标准很简单——你手边正好有一段读不下去的材料，里面有个词卡住了你。
